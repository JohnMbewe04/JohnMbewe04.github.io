BringUp

An agent that proves firmware works on the wire

Takes a sensor datasheet and an ESP32 board, then writes, flashes and verifies a driver, using a logic analyser on the real bus as proof.

Overview

Coding agents can write firmware, but nobody knows it works until it runs on hardware. BringUp closes that loop with a USB logic analyser that costs about RM 30.

The key design rule is that the LLM proposes and explains, while deterministic code measures and judges. A run passes only when the verifier says so from real bus and serial evidence, never because the model claims success.

What I did

  1. 01Designed the agent loop: ingest datasheet → plan → preflight wiring → implement → build → flash → observe → verify → diagnose.
  2. 02Split the work across NVIDIA Nemotron models: Ultra for datasheet reasoning and diagnosis, Super for code generation, Nano for log triage and quick fixes.
  3. 03Built a hardware bridge: PlatformIO build and upload, serial capture, and sigrok-cli I²C/SPI decoding.
  4. 04Defined the fault demos: wrong address, missing pull-up and a fake BMP280 sold as a BME280, each diagnosed from bus evidence with a datasheet page citation.
